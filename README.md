# Health Score

日々の体重・食事・運動を記録し、100点満点のスコアで健康行動を振り返るための個人用PWAです。

**Current version: v0.6.52**

## 主な機能

- 1日の健康行動を100点満点でスコア化
- 体重、朝食、昼食、帰宅時の買い食い、夕食、たんぱく質、歩数、HIIT / 運動を記録
- 摂取カロリー・たんぱく質実績の記録
- 体重推移グラフ
- カレンダーと週間サマリー（前週比較・改善点・次の小さな目標）
- 体重の直近7日と前7日の比較、変動の読み取り
- 体調不良・出張・疲労回復時の計画休養（既存の運動5点枠に対応）
- 小さな達成の表彰（累計記録・週間平均・買い食い◎）
- JSONバックアップの書き出し履歴・定期バックアップ推奨
- JSONバックアップ / 復元
- PWAとしてホーム画面から起動
- Firebase Cloud MessagingによるPush通知
- 毎日 7:00 / 17:30 / 21:00 のリマインド
- 通知タップで関連する入力欄へ直接移動
  - 朝 → 体重
  - 夕方 → 買い食い
  - 夜 → その日の最初の未入力項目

## データについて

健康記録データはブラウザの `localStorage` に保存されます。
記録内容そのものをGitHubやFirebaseへ送信する仕組みはありません。

Push通知にはFirebase Cloud MessagingとGitHub Actionsを利用しています。
